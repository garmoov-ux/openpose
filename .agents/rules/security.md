# 보안 및 환경 변수 관리 표준 규칙 (security.md)

- **적용 대상**: 전체 프로젝트 파일, 환경 변수(`.env*`), 외부 통신 서비스, 클립보드 API
- **작성 기준**: 2026년 11월
- **원칙**: 어떠한 비밀 키나 토큰도 저장소에 노출되지 않도록 원천 차단하고, 웹 캔버스 및 통신 파이프라인의 취약점을 선제적으로 방어한다.

---

## 1. 환경 변수(`.env`) 관리 및 노출 방지 규칙

1. **실제 환경 설정 파일(`.env`, `.env.local`)의 Git 커밋 절대 금지**:
   - `.env`, `.env.local`, `.env.*.local` 파일은 `.gitignore`에 필수로 등록되어야 하며, 실제 시크릿 키나 인증 토큰을 절대 리포지토리에 푸시하지 않는다.
2. **`.env.example` 템플릿 유지 의무**:
   - 프로젝트에 새 환경 변수가 추가될 때마다 반드시 `.env.example`에 기본값 또는 더미 플레이스홀더를 작성하여 협업자에게 필수 키 목록을 제공한다.
3. **`VITE_` 접두사 클라이언트 번들링 주의**:
   - Vite 환경에서 `VITE_`로 시작하는 환경 변수는 브라우저 번들 자바스크립트 코드에 평문(Plain Text)으로 포함된다.
   - 데이터베이스 비밀번호, 관리자 시크릿 토큰 등 서버 사이드 민감 정보는 절대 `VITE_` 접두사로 선언하지 않는다.
   - ComfyUI 기본 엔드포인트 URL(`VITE_COMFY_URL`)과 같은 공개용 클라이언트 설정만 `VITE_`로 선언한다.

---

## 2. 외부 데이터 입력 및 JSON 스키마 검증

1. **포즈 JSON 파일 파싱 보안**:
   - 사용자가 외부에서 불러오는(Import) 포즈 프리셋 JSON 파일은 역직렬화 시 임의 코드 실행(Prototype Pollution)을 유발하지 않도록 필드 검증을 거친다.
   - 각 본 이름이 `JOINT_DEFINITIONS`에 정의된 허용 목록에 존재하는지 확인하고, 쿼터니언 배열(`x, y, z, w`)이 유효한 숫자 범위인지 검증 후 적용한다.
2. **XSS 및 DOM 인젝션 방어**:
   - 사용자 정의 프리셋 이름이나 텍스트를 DOM에 렌더링할 때 `innerHTML`을 절대 사용하지 않으며, React의 안전한 텍스트 바인딩만을 사용한다.

---

## 3. 네트워크 통신 및 ComfyUI 보안

1. **로컬 호스트 주소 제한**:
   - ComfyUI 통신 기본 주소는 로컬 환경(`http://127.0.0.1:8188` 또는 `localhost`)으로 제한하며, 사용자가 임의의 외부 URL을 입력할 때는 경고를 표시한다.
   - 내부망 비인가 주소(SSRF)로의 맹목적인 요청을 방지하기 위해 허용된 프로토콜(`http:`, `https:`, `ws:`, `wss:`)만 연결을 허용한다.
2. **CORS 및 프록시 안전성**:
   - 개발 환경 프록시(`vite.config.ts`)는 로컬 ComfyUI 서버와의 원활한 통신을 위해 허용하되, 불필요한 모든 경로를 와일드카드로 열어두지 않고 `/api/comfy` 전용 경로로 한정한다.

---

## 4. 브라우저 API 보안 및 권한 처리

1. **클립보드 API 권한 예외 처리**:
   - `navigator.clipboard.write`는 보안 컨텍스트(HTTPS 또는 localhost)에서 사용자의 직접적인 제스처(클릭 이벤트) 내에서만 동작한다.
   - 브라우저 보안 정책에 의해 권한이 거부되거나 예외가 발생하더라도 앱 전체가 크래시되지 않도록 `try-catch`로 감싸고 사용자에게 다운로드 Fallback을 제공한다.
