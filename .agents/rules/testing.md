# 테스트 및 렌더링 품질 검증 규칙 (testing.md)

- **적용 대상**: 전체 프로젝트 단위 테스트, 3D 뷰포트 E2E 테스트, 회귀 테스트
- **작성 기준**: 2026년 11월
- **원칙**: 3D 수학 연산의 수치적 무결성과 캔버스 렌더링 결과물의 픽셀 단위 일관성을 자동화된 테스트로 상시 검증한다.

---

## 1. 테스트 계층 구조 및 분업 기준

1. **단위 테스트 (Unit Tests - 수학 및 파이프라인 연산)**:
   - 쿼터니언 각도 변환, 본 계층 상대 좌표 계산, 바운딩 박스 계산 등 순수 함수를 검증한다.
   - OpenPose 2D 투영 좌표 변환 및 COCO 18 키포인트 JSON 직렬화 스키마를 검증한다.
   - 외부 Three.js 캔버스 없이 메모리 상에서 1초 이내에 완료되어야 한다.
2. **E2E 및 뷰포트 인터랙션 테스트 (Playwright)**:
   - 브라우저를 구동하여 캔버스 로딩, 기즈모 회전 드래그, 카메라 프리셋 클릭 시 뷰포트 반응을 검증한다.
   - 렌더링 모드(OpenPose, Depth, Normal, Canny) 전환 시 캔버스 픽셀 스크린샷 회귀 테스트를 수행한다.
3. **ComfyUI 통합 통신 테스트 (Integration / Mock)**:
   - 실제 로컬 ComfyUI 서버가 꺼져 있을 때의 연결 장애 안내(`127.0.0.1:8188`) 및 WebSocket 재연결 루프를 Mock 테스트한다.

---

## 2. 3D 렌더링 및 캔버스 캡처 검증 원칙

1. **오프스크린 렌더링 해상도 무결성**:
   - `captureSnapshot(512)` 및 `captureSnapshot(1024)` 호출 시 생성된 Base64 DataURL이 유효한 PNG 헤더(`data:image/png;base64,iVBORw...`)를 포함하는지 검증한다.
   - 캡처된 캔버스의 너비와 높이가 정확히 지정된 픽셀 규격과 일치해야 한다.
2. **GPU 컨텍스트 누수(Context Leak) 차단**:
   - 렌더러 생성 및 해제 반복 시 WebGL Context Loss 이벤트(`webglcontextlost`)가 적절히 수습되는지 확인한다.
   - 컴포넌트 마운트/언마운트 시 활성 WebGL 컨텍스트 개수가 1개를 초과하여 유지되지 않도록 방어한다.

---

## 3. 테스트 실행 및 통과 기준

1. **빌드 전 사전 검증**:
   - 코드를 Git에 커밋하거나 배포하기 전 반드시 `npm run build`를 실행하여 TypeScript Strict 컴파일 에러가 0건임을 확인한다.
2. **결함 보고 원칙**:
   - 렌더링 결함이나 관절 회전 오차가 발생했을 때는 임의로 값을 하드코딩해 넘기지 않고, 기하 연산 공식과 행렬 변환 단계를 디버깅하여 근본 원인을 수정한다.
